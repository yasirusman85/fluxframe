# E2E (Playwright) — helper API and how page agents write specs

- Config: `playwright.config.ts`. Projects: `chromium` (desktop 1360×860, every spec), `mobile` (Pixel 7 on Chromium, only `*.mobile.spec.ts`), `demo` (only with `DEMO=1`; specs live in `e2e/demo/`). The Vite server on `127.0.0.1:4173` starts automatically (`vite preview` on CI after `npm run build`). Run `npm run e2e`, `npm run e2e:ui`, `npm run e2e:report`.
- Setup order in `test.beforeEach` (from `./helpers`): `resetStorage(page)` → `seedProjects(page, [...])` / `setCredits(page, n)` (or `seedStorage(page, { projects, credits })`) → `mockPollinations(page, { delayMs?, failTimes?, status? })` → `gotoApp(page, "/create/image")`. Reset/seed run once per tab, so `page.reload()` keeps what the app persisted. Without a project seed the library boots with the six sample image projects; `seedProjects(page, [])` gives an empty library; `sampleProjectFixture(overrides)` is a complete completed image project.
- `mockPollinations` serves `e2e/fixtures/keyframe.jpg` for every `image.pollinations.ai` request (fonts are blocked too) and returns `{ requests }`. `status` 403 (default) makes the client back off 15 s before retrying; use `status: 500` for a quick retry test.
- Generation: fill `prompt-input`, click `generate-button`, `await waitForJobComplete(page)` (fails fast when the queue panel shows retry). Video studios: duration 3 and `test.setTimeout(60_000)`. Uploads: `uploadToDropzone(page, "keyframe-dropzone", FIXTURES.keyframe)` (also `FIXTURES.portrait`, `.packshot`, `.speech`).
- Assertions: `expectToast(page, /text/, "warning"?)`; every page spec includes `checkA11y(page, { exclude?, include?, disableRules? })`, which fails on critical/serious WCAG 2.0 A/AA violations (`canvas-root` is always excluded). Prefer `getByTestId` with the ids from `docs/SPEC.md`; use role/text locators only where no id exists.
- Contracts the smoke specs assume of the shell: exactly one `data-testid="sidebar"` element in the DOM; the closed mobile drawer is unmounted or `display:none` (not just translated off-screen); typing "cinema" in the palette lists Cinema Studio first and ArrowDown + Enter opens it; the palette input is focused on open; NotFoundPage renders a home/explore/back link inside `<main>`; breadcrumb text equals the SPEC route title.
